# P2P GPS Protocol

P2P GPS の Bluetooth 通信仕様と、仕様を確認するための Python 実装・テストデータです。

- 仕様の正式なファイル: [`spec/protocol-v1.md`](spec/protocol-v1.md)
- Python 実装: `p2pgps/`
- テスト: `tests/`
- テストデータ: `tests/vectors/`

## 使い方

```bash
python -m pip install -e ".[test]"
python -m pytest
```
